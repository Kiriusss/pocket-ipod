# Pocket · 你的本地 iPod

一台可以真实播放本地音乐的网页版 iPod。经典机身、可旋转点击式转盘、分层菜单，以及属于自己的曲库。

**在线使用：https://kiriusss.github.io/pocket-ipod/**

## 试听

点击“先听一段”，浏览器会现场合成一段原创 WAV 音轨，不连接音乐服务。

也可以点击“选择本地音乐”，或将音乐文件拖入页面。支持浏览器能够解码的 MP3、M4A、WAV、FLAC、OGG 等文件；具体编解码能力取决于浏览器和设备。受保护的 DRM 音乐不能作为普通音频播放。

## 操作

- 在转盘外圈画圈，或使用鼠标滚轮，浏览菜单。
- 中心键：确认；MENU：返回。
- 底部播放键：播放 / 暂停；左右键：上一首 / 下一首。
- 长按左右键：快退 / 快进。
- 正在播放时转动转盘：调节音量。
- 屏幕上的进度条：拖动到想听的位置。
- HOLD：锁定机身按键，音乐继续播放。
- 键盘 ↑ / ↓ 浏览，Enter 确认，Esc 返回，空格播放 / 暂停，← / → 切歌。
- “设置”中可切换随机、循环、转盘声、音量与机身颜色。
- 页面右上角“夜间”切换黑夜模式，iPod 同时变成黑色；可在“设置”中切换，浏览器会记住选择。

## 经典小游戏

在 iPod 主菜单打开“游戏”，可玩打砖块、降落伞和完整 Klondike 纸牌。它们是按经典玩法重新实现的游戏，不使用原厂固件。

- 打砖块：转盘或 ← / → 移动挡板，中键发球。三条生命、三关。
- 降落伞：转盘或 ← / → 瞄准，中键发射；阻止同侧四名伞兵落地。
- 纸牌：转盘选择牌堆，中键取牌或放牌；↑ / ↓ 选择列内的牌，也可点屏幕。U 撤回。
- 播放键暂停，MENU 返回，R 重新开始。HOLD 和切到后台会暂停游戏。
- 进入游戏会暂停音乐。退出后可自行继续播放。

## NCM 本地解包与下载

选择或拖入 `.ncm` 文件即可在浏览器内解包，随后使用解包出的 MP3 或 FLAC 播放。歌曲右侧的 **↓** 按钮可将解包音乐保存到设备。输出保留原始音频编码，不进行有损转码。

解包、元数据与内嵌封面读取均在本地完成，不请求在线封面地址，不使用解包服务器。保留曲库时只保存解包后的浏览器副本。损坏、缺失音频或不支持的封装会提示导入失败，其他歌曲仍可继续导入。

## 音乐隐私

音乐、内嵌封面和标签只在浏览器中读取。音频使用 `File` → `URL.createObjectURL()` → HTML Audio 播放，不上传至服务器。

- 页面没有上传接口、账号、追踪或外部 CDN。
- CSP 设置 `connect-src 'none'`，禁止页面通过 fetch、XHR、WebSocket 等联网。
- `media-src blob:` 只允许浏览器本地 Blob 音源。
- 封面只接受大小受限的内嵌光栅图片，通过 Blob URL 显示。
- 默认关闭页面后不保留歌曲；刷新需重新选择。
- 可选“在此浏览器保留曲库”使用 IndexedDB 保存在本设备的浏览器存储中。
- 关闭保留选项或清空曲库会删除浏览器中的已保留副本，不影响原始文件。
- 音乐文件不会写入代码目录或版本库。

打开在线页面仍需要下载网页代码，托管服务可能处理正常的访问日志；所选音乐不包含在请求中。

## 本地运行

```sh
python -m http.server 4322 --bind 127.0.0.1
```

访问 http://127.0.0.1:4322 。请通过 HTTP 服务运行，不要直接双击 HTML 文件。

## 项目文件

- `app.js`：界面、转盘、菜单、键盘、拖入文件、演示音轨。
- `player.js`：本地音频控制与队列。
- `library.js`：本地元数据、封面和可选持久曲库。
- `vendor/jsmediatags.min.js`：本地提供的元数据读取库。
- `tests/`：自动测试。

这是独立的 iPod 风格项目，与 Apple 无关联。参考经典 iPod 的交互方式，不包含 Apple 的实现代码或音乐。
